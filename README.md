# 🩻 X-RAI: Onchain AI Medical Diagnostics

> **MetaMask Smart Accounts x Monad x Envio Hackathon**  
> AI-Powered Medical X-Ray Training with Gasless Smart Accounts & ERC-7710 Delegation

Interactive 3D medical visualization combining **AI diagnostics**, **face-swapping**, **real-time X-ray effects**, and **MetaMask Smart Accounts** for gasless AI consultations and verifiable medical achievements.

## 🎯 What Makes This Unique

**Gasless AI Medical Experience** - Train as a medical professional with AI assistance, powered by smart account abstraction. No gas fees for consultations, instant Monad finality, and real-time Envio activity tracking.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) - Connect MetaMask to enable smart account features.

## ✨ Features

- **3D X-Ray Visualization** - WebGL shaders, face-swapping, interactive scanning
- **AI Medical Analysis** - Voice consultation, diagnostic markers, treatment suggestions  
- **Gasless Smart Accounts** - ERC-4337 + ERC-7710 delegation for zero-fee AI consultations
- **NFT Achievements** - Mint verifiable diagnostic certificates onchain

## 🚀 Technology Stack

- **Frontend**: Next.js 15, TypeScript, Three.js, WebGL shaders
- **Web3**: MetaMask Delegation Toolkit (`@metamask/delegation-toolkit@0.13.0`), Viem 2.38
- **Smart Accounts**: ERC-4337, ERC-7710, Hybrid implementation
- **Blockchain**: Monad Testnet (10143), Alchemy RPC
- **Indexing**: Envio HyperSync, GraphQL
- **AI/ML**: Cerebras inference, ElevenLabs voice, face-api.js
- **Contracts**: Hardhat, TypeChain, deployed & verified


## 🎮 Demo Flow

1. Connect MetaMask → Complete delegation onboarding
2. Upload face → AI face-swaps onto 3D skeleton  
3. Scan with mouse → Discover medical conditions
4. Click "CONSULT AI" → Get voice diagnosis (gasless)
5. Submit diagnosis → Mint NFT achievement certificate
